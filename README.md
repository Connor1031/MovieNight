# Movie Night

A simple movie tracker for saving a watchlist and keeping ratings and notes.


## Run the project

Install Python 3, then open two terminals in the `resource project` folder.

In the first terminal, start the API:

```powershell
python server.py
```

In the second terminal, serve the client:

```powershell
python -m http.server 8000 --bind localhost
```

Open http://localhost:8000 in your browser.


## Resource and attributes

The resource is a movie. Each movie has seven attributes besides its ID.

| Attribute | Data type | Description |
| --- | --- | --- |
| `id` | Integer | Unique identifier generated by SQLite |
| `title` | Text | Required, nonempty movie title |
| `director` | Text | Director name; blank or omitted values become `NA` |
| `release_year` | Integer or null | Whole number from 1 to 9999; blank values are stored as null and displayed as `NA` |
| `genre` | Text | Genre; blank or omitted values become `NA` |
| `watch_status` | Text | Dropdown offers `Want to Watch` and `Watched`; the API also accepts `NA` for missing values |
| `rating` | Integer or null | Whole number from 1 to 5; `Not watched` is stored as null |
| `notes` | Text | Personal thoughts (labeled Thoughts in the form); blank or omitted values become `NA` |


## Database schema

`database.py` contains the `MovieDatabase` class. It creates the table using
`schema.sql` and handles all database operations with parameterized queries.


## REST API endpoints

The base URL is `http://localhost:5000`. Replace `{id}` with a movie's numeric ID.

| Name | HTTP method | Path | Success response |
| --- | --- | --- | --- |
| List movies | `GET` | `/movies` | `200 OK` and a JSON array (empty collection: `[]`) |
| Retrieve movie | `GET` | `/movies/{id}` | `200 OK` and a JSON movie object |
| Create movie | `POST` | `/movies` | `201 Created`, saved JSON movie, and `Location: /movies/{id}` |
| Replace movie | `PUT` | `/movies/{id}` | `200 OK` and the replaced JSON movie |
| Delete movie | `DELETE` | `/movies/{id}` | `204 No Content`, with no response body |
| Collection preflight | `OPTIONS` | `/movies` | `204 No Content` |
| Member preflight | `OPTIONS` | `/movies/{id}` | `204 No Content` |

POST and PUT require a JSON object and the header `Content-Type: application/json`.


### CORS

Every API response includes these headers:

```text
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS
Access-Control-Allow-Headers: Content-Type
```
